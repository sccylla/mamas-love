# Name-card bouquet

`name-card-bouquet.png` is a custom floral illustration generated for Mama’s Love: peach roses, magenta peonies, ivory flowers, lilac accents, and green foliage on a transparent background. It contains no lettering or brand marks.

The name-card canvas renderer reuses this one local asset around the border. Its protected centre keeps names, pronunciation, and meaning readable. The name-card gallery uses the same asset. The original generation is preserved in the workspace’s `generated_images` directory; the website uses the copy in this directory.
