# Mama’s Love identity

The embracing-heart symbol combines two figures in warm rose and apricot. The wordmark uses outlined DM Sans lettering, so it renders consistently without loading a font.

- `mamas-love-logo.svg`: horizontal lockup for light backgrounds.
- `mamas-love-logo-on-dark.svg`: horizontal lockup used in the header and footer.
- `mamas-love-mark.svg`: standalone transparent vector symbol.
- `apple-touch-icon.png`: 180px Apple home-screen icon.
- `icon-192.png` and `icon-512.png`: web-manifest icons.
- `../favicon.svg`: matching symbol on a plum tile, also mirrored at `/favicon.svg`.

Colours: plum `#352044`, rose `#ff79a5`, apricot `#ffcba7`, and light wordmark `#fff0f4`. Preserve the proportions and leave at least one head diameter of space around the logo. The source font’s license is included at `../fonts/OFL-DM-Sans.txt`.

Icons are rasterised from the same SVG artwork. The site uses local assets only; the identity adds no external requests or runtime dependencies.
