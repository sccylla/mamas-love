Home pregnancy test

Scan the result window

For the clearest result, photograph the test straight-on in good light, within the reading time stated in the test instructions.

1

Use the correct reading window. Results read too early or too late can be misleading.

2

Keep the control area visible. A missing control line/symbol usually means the test is invalid.

3

Confirm what the scanner sees. Photo analysis is only an aid; brand instructions take priority.

Important:

A positive home test is usually reliable when used correctly. A negative result can be false if you tested too early. If the result is negative but your period is still late, repeat according to the test instructions or contact a clinician.

Why the report's own range matters:

Reference ranges vary between laboratories, test methods, ages and other factors. A value outside the printed range does not automatically mean disease, and a value inside the range does not rule one out.

VERIFY
BEFORE YOU READ A RESULT

Start with the test instructions.

Home pregnancy tests differ by brand, so instructions and timing matter. Lab results should be compared with the reference range on the actual report and interpreted in the context of symptoms, history and other tests.
