# Mama's Love

A polished responsive maternal and baby-care educational website with three functional browser-based trackers:

- Pregnancy tracker (LMP + cycle-length adjustment, gestational age, trimester, due date)
- Period tracker (cycle day, next period, estimated ovulation and fertile window)
- Newborn development tracker (chronological age, corrected age for preterm babies, first-year milestone stage)

## Run locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.

## Deploy

This is a static site and can be deployed directly to Vercel, Netlify, Cloudflare Pages or any static host. No build step is required.
